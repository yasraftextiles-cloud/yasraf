## 🌟 About YASRAF Clothing
**YASRAF Clothing** is a premium Pakistani women's fashion and luxury prêt brand dedicated to craftsmanship, timeless aesthetics, and contemporary cuts. From everyday pret to festive luxury lawn and bespoke formal ensembles, each piece embodies sophistication and artistry.

---

## ✨ Features
- **Luxury Eastern Prêt & Formals**: Exclusively curated Pakistani women's fashion collections.
- **Interactive Shop-the-Look Hotspots**: Direct shoppable lookbook with lace, cuff, dupatta, and embroidery callouts.
- **Real Product Gallery**: Multi-angle studio photoshoot view, fabric details, and care instructions.
- **1-Click WhatsApp Ordering**: Instant direct order via WhatsApp (`wa.me`) with prefilled product title, SKU, and size.
- **Live Stock & Size Selection**: Real-time stock status (In Stock / Low Stock) and XS–XL sizing options.
- **Cart & Slide-over Drawer**: Seamless add-to-bag, quantity management, and express checkout flow.
- **Single-Line Desktop Navigation**: Clean, ultra-sleek luxury header matching international fashion houses (Khaadi, Limelight).
- **Responsive & Fast**: Built with React 19 and Vite with instant HMR and responsive mobile/desktop design.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/yasraftextiles-cloud/yasraf.git
cd yasraf
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
